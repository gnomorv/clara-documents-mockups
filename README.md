# Clara Studio — Documents tree view (mockup)

A standalone, interactive mockup of the Documents tab with the proposed **tree view**:
every shelf of a project (1 Intake, 2 Design, 3 Delivery, 4 Handover, Client material)
expanded with its documents beneath, dashed guide lines, a chevron to fold each shelf,
and a second example showing the organisation library with a nested folder.

All data is fictional and hard-coded in `index.html`. No backend, no build step.
Open `index.html` locally or visit the GitHub Pages site for this repository.
